## Нативный каталог и Quick Print

- Каталог больше не открывает сайты. Карточки приходят из JSON API Printables, MakerWorld, Thingiverse и Cults3D: фото слева, название, площадка, автор, платность и лицензия справа. Поиск по запросу, тегам, ссылке и подгрузка страниц.
- Quick Print из карточки: принтер, собственные пресеты филамента и процесса, цвет, интерактивный стол, высота слоя, заполнение и стенки. Компоновка по образцу Bambu Handy.
- Модель можно перемещать двойным тапом прямо в Quick Print или открыть полный стол, изменить положение/поворот/масштаб и вернуться. Локальная нарезка возвращает к подготовке; просмотр слоёв доступен отдельно.
- Отправка G-code и запуск печати остаются отдельными действиями с подтверждением пластика и свободного стола. Изменение модели, профиля или принтера сбрасывает старый G-code.
- «В центр» использует оригинальную иконку основной панели OrcaSlicer. Видимые размеры четырёх значков на столе выровнены; для оригинальных цветных значков есть тёмные варианты.
- Сохранён кэш моделей с настраиваемым сроком (по умолчанию 7 дней). Для фото Printables используются небольшие миниатюры.

### Доступ к площадкам

Поиск Printables и MakerWorld работает без ключа. Thingiverse требует собственный App Token, Cults3D — ник и API key. Они задаются через **«Модели» → API** и шифруются Android Keystore, отдельно от профилей и резервных копий.

Открытые STL Printables загружаются непосредственно через API. Защищённые файлы могут потребовать личную сессию Printables или access token Bambu. **Cults API не предоставляет файлы**: к карточке можно прикрепить ранее полученный STL / ZIP / 3MF. Если API не сообщает цену, интерфейс указывает это явно; цена и лицензия не смешиваются. Площадки могут менять API и ограничения доступа.

3MF пока импортируется как геометрия одного объекта и материала: настройки автора, AMS и распределение по столам не переносятся. Поддерживаются Android 14+ и ARM64.

### Проверка

Проверены живые анонимные поиск и подробности Printables/MakerWorld и получение STL Printables. Адаптеры авторизованных площадок проверены по контрактам API с тестовыми ответами; личные аккаунты без ключей пользователя не проверялись. JVM-тесты, Android-проверки жестов и Quick Print, lint и установка на эмулятор Android 14 выполнены перед публикацией.

APK сохраняет прежнюю подпись и устанавливается поверх 0.5.0. Для проверки файла рядом опубликован SHA256SUMS. Обновлены README и инструкция каталога.
