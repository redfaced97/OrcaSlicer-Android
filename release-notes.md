Исправления загрузки и работы с профилями, настройки приложения в одном месте.

- Единое окно прогресса для моделей: получение ссылки, скачивание с процентами при известном размере и проверка файла. Убраны дублирующиеся индикаторы и наложение диалогов.
- Отправка G-code показывает передачу и ожидание подтверждения принтера. Ошибка сбрасывает индикатор; загрузку можно повторить. Обычная загрузка не запускает печать.
- Дискета сохраняет выбранный пользовательский профиль. Для штатного профиля создаётся пользовательская копия. «Сохранить как» остаётся доступным.
- `*` показывает несохранённые в именованный профиль изменения на столе, в параметрах, библиотеке и Quick Print. Рабочие правки сохраняются между запусками; возврат к исходным значениям убирает звёздочку.
- Исправлены гонка быстрого выбора профилей, ввод в Quick Print после смены профиля и описание сброса параметров.
- «О программе» → шестерёнка: язык, графика / Dev menu, API каталогов, кэш, телеметрия и обновления. Быстрые виды камеры доступны в предпросмотре.
- Обновлены русская и английская инструкции.

Android 14+, ARM64. Подпись совместима с предыдущими APK; удалять приложение перед обновлением не требуется.
