Тестовая версия для Android 14+ / ARM64.

- Исправлен перенос модели: двойной тап с удержанием больше не приближает камеру.
- Щипок двумя пальцами и вращение камеры сохранены.
- Библиотека пользовательских профилей, 638 параметров, просмотр слоёв и Moonraker.
- README со скриншотами и инструкциями по импорту настроек.

APK подписан тем же ключом, что и предыдущие локальные сборки: его можно установить поверх 0.4.0. Скачивайте OrcaSlicer-arm64-v0.4.1.apk в Assets.

Проверено: 42 JVM-теста, 2 Android-теста жестов и сохранения, lint без ошибок.
