# Обновления приложения

[← Русский README](../README.md) · [English README](../README.en.md)

Обновлятор встроен начиная с **0.6.2**. Эту версию сначала нужно установить из [GitHub Releases](https://github.com/redfaced97/OrcaSlicer-Android/releases/latest). Следующие релизы можно получать из приложения.

## Загрузка и установка

1. Откройте **«О программе» → «Обновления приложения» → «Проверить»** либо нажмите уведомление о новой версии.
2. Прочитайте список изменений в приложении и нажмите **«Скачать апдейт»**.
3. Загрузка выполняется системным менеджером Android: можно закрыть приложение; после временной потери сети она продолжится. Кнопка **«В фоне»** закрывает диалог, **«Отменить загрузку»** отменяет скачивание.
4. После загрузки приложение проверяет размер, SHA-256, имя пакета, более новый код версии, подпись и наличие ARM64-движка. Несовместимый или повреждённый APK не передаётся установщику.
5. Пока приложение открыто, готовое обновление автоматически передаётся системному установщику. Если оно закрыто, появится уведомление **«Готова к установке»**. Установку также можно продолжить из «О программе».
6. Android при необходимости предложит разрешить установку из **OrcaSlicer**. Включите разрешение и вернитесь в приложение; затем подтвердите установку APK. Если отказались, проверенный файл остаётся доступен для повторной установки.

Обычное Android-приложение требует системного подтверждения установки. Полностью скрытая установка и обход разрешений не используются. Профили, настройки, подключения и модели сохраняются при обновлении с прежней подписью. Во время локальной нарезки, импорта модели или загрузки G-code открытие установщика откладывается.

## Уведомления и автоматическая проверка

При первом запуске 0.6.2 приложение попросит разрешение на уведомления. Можно изменить его позже через «О программе» или системные настройки Android. Если уведомления запрещены, новая версия всё равно будет показана внутри приложения.

Автопроверка включена по умолчанию: при запуске не чаще раза в 6 часов, а также примерно раз в сутки в фоне. Android может отложить фоновую проверку из-за отсутствия сети или экономии энергии. Переключатель в «О программе» отключает автоматическую проверку; ручная кнопка продолжает работать.

Проверяются только стабильные ARM64-релизы [redfaced97/OrcaSlicer-Android](https://github.com/redfaced97/OrcaSlicer-Android/releases). Бета-теги, nightly, черновики и APK без контрольной суммы не предлагаются. «Позже» убирает повторное всплывающее предложение этой версии; карточка обновления остаётся доступна в «О программе».

## Технические источники

Используются [GitHub Releases API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release), [Android DownloadManager](https://developer.android.com/reference/android/app/DownloadManager), сертификаты подписей пакетов через Android PackageManager и системный установщик APK. Собственного сервера обновлений и пароля GitHub не требуется.
